# فروشگاه (Froshgah) 🏪

ربات تلگرامی + سامانه جمع‌آوری برای **پیدا کردن فروشگاه‌های پوشاک در اینستاگرام و تلگرام**.

این پروژه جایگزین پروژه قبلی مخزن (`sms-forwarder`) شده و کاملاً بازنویسی شده است.

## قابلیت‌ها

- 🔍 **جستجوی فروشگاه‌ها** از طریق ربات تلگرام (`/search`) یا خط فرمان
- 📸 **جمع‌آوری اینستاگرام** با `instaloader` (هشتگ یا کلیدواژه) — درخواستی
- ✈️ **جستجوی سراسری تلگرام** با `Telethon` (پیام‌ها + کانال‌های پیداشده) — درخواستی
- 🤖 **ربات تلگرامی** برای جستجو، آمار و اجرای جمع‌آوری توسط مدیر
- 💾 ذخیره در **SQLite** با جلوگیری از رکورد تکراری و ادغام اطلاعات
- 🔎 نرمال‌سازی متن فارسی (ی/ی، ک/ک، نیم‌فاصله، ارقام فارسی) برای جستجوی دقیق
- 📱 استخراج خودکار **شماره تلفن، آیدی اینستاگرام، آیدی تلگرام، لینک‌ها، شهر و دسته‌بندی**

## پیش‌نیازها

- پایتون **۳.۱۰ یا جدیدتر**
- یک **ربات تلگرام** (از @BotFather)
- **API ID و API Hash** تلگرام از [my.telegram.org](https://my.telegram.org)
- (اختیاری) اکانت اینستاگرام برای پایداری بیشتر

## نصب

```bash
pip install -r requirements.txt
# برای توسعه/تست:
pip install -r requirements-dev.txt
```

## پیکربندی (`.env`)

```bash
cp .env.example .env
```

سپس مقادیر را پر کنید:

| متغیر | از کجا؟ |
|---|---|
| `TELEGRAM_BOT_TOKEN` | ربات بسازید در [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_OWNER_ID` | شناسه عددی شما؛ از [@userinfobot](https://t.me/userinfobot) |
| `TG_API_ID` / `TG_API_HASH` | [my.telegram.org](https://my.telegram.org) → API Development Tools |
| `IG_USERNAME` / `IG_PASSWORD` | (اختیاری) اکانت اینستاگرام شما |

> ⚠️ فایل `.env` داخل گیت نمی‌رود (در `.gitignore` است). هرگز توکن‌ها را در چت یا کد نگذارید.

## راه‌اندای قدم‌به‌قدم

### ۱) ساخت دیتابیس

```bash
python -m froshgah init
```

### ۲) لاگین تلگرام (یک‌بار، در ترمینال)

```bash
python -m froshgah login
```

شماره تلگرام و کد تأیید را در ترمینال وارد می‌کنید؛ فایل سشن (`froshgah.session`) ساخته می‌شود.

### ۳) جمع‌آوری (درخواستی — هر وقت خواستید)

```bash
# اینستاگرام با هشتگ
python -m froshgah collect ig --hashtag پوشاک --limit 30

# اینستاگرام با کلیدواژه (خودش هشتگ‌های مرتبط را پیدا می‌کند)
python -m froshgah collect ig --keyword "فروشگاه پوشاک" --limit 30 --bios

# تلگرام (جستجوی سراسری + خواندن چند پیام اخیر کانال‌های پیداشده)
python -m froshgah collect tg "فروشگاه پوشاک" --limit 40
```

### ۴) جستجو

```bash
python -m froshgah search "مانتو تهران"
python -m froshgah latest
python -m froshgah stats
```

### ۵) اجرای ربات تلگرام

```bash
python -m froshgah bot
```

## دستورات ربات

| دستور | توضیح |
|---|---|
| `/start` — `/help` | راهنما |
| `/search <عبارت>` | جستجو در فروشگاه‌های ذخیره‌شده |
| `/latest` | ۱۰ فروشگاه اخیر |
| `/stats` | آمار دیتابیس |
| `/collect_ig <هشتگ> [تعداد]` | جمع‌آوری اینستاگرام (**فقط مدیر**) |
| `/collect_tg <عبارت>` | جستجوی تلگرام (**فقط مدیر**) |

## محدودیت‌ها و نکات مهم ⚠️

- **اینستاگرام API رسمی برای جستجو ندارد**؛ `instaloader` یک ابнат غیررسمی است و اینستاگرام می‌تواند محدودیت (Rate-limit) یا بلاک بدهد. با تعداد کم و فاصله `REQUEST_DELAY` اجرا کنید و از اکانت اصلی خودتان استفاده نکنید.
- **تلگرام**: جستجوی سراسری با اکانت کاربری (MTProto) انجام می‌شود؛ نتایج شامل کانال/گروه‌هایی است که در دسترس شما هستند.
- رعایت قوانین حریم خصوصی، شرایط استفاده (ToS) و قوانین محلی الزامی است؛ از اطلاعات فقط برای اهداف مجاز (مثلاً تحقیق بازار یا لیست‌کردن با رضایت صاحبان پیج) استفاده کنید و برای تماس تکراری/اسپم استفاده نکنید.
- هیچ‌کدام از توکن‌ها و رمزهای شما از مخزن خارج نمی‌شود.

```
├── __main__.py          # ورودی python -m froshgah
├── cli.py               # دستورات خط فرمان

├── config.py            # خواندن .env
├── db.py                # دیتابیس SQLite + جستجو
├── extract.py           # استخراج تلفن/آیدی/شهر/دسته از متن
├── normalize.py         # نرمال‌سازی متن فارسی
├── models.py            # مدل Store
├── ui.py                # نمایش نتایج
└── collectors/
    ├── instagram.py     # instaloader (هشتگ/کلیدواژه)
    └── telegram.py      # telethon (جستجوی سراسری + لاگین)
tests/                   # تست‌های unit
```
