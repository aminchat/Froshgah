# فروشگاه (Froshgah) 🏪

پیدا کردن **فروشگاه‌های پوشاک** از اینستاگرام و تلگرام — با یک سایت جستجوی ساده روی **GitHub Pages** و جمع‌آوری خودکار روی **GitHub Actions**.

> 💡 **نیاز به نصب پایتون ندارید:** همه‌چیز روی خود گیت‌هاب اجرا می‌شود (بخش «اجرا روی GitHub»).
> کدهای پایتون فقط «موتور» پروژه‌اند و داخل گیت‌هاب اجرا می‌شوند؛ شما فقط از مرورگر استفاده می‌کنید.

## اجرا روی GitHub (بدون نصب چیزی) — توصیه‌شده

### ۱) رازها (Secrets) را تعریف کنید
مسیر: **Settings → Secrets and variables → Actions → New repository secret**

| نام راز | مقدار | لازم است؟ |
|---|---|---|
| `IG_USERNAME` / `IG_PASSWORD` | یک اکانت اینستاگرام (ترجیحاً نه اصلی‌تان) | اختیاری، ولی نتیجه خیلی بهتری می‌دهد |
| `TG_API_ID` / `TG_API_HASH` | از [my.telegram.org](https://my.telegram.org) → API development tools | فقط برای جمع‌آوری تلگرام |
| `TG_SESSION_B64` | خروجی `base64 -w0 froshgah.session` | فقط برای جمع‌آوری تلگرام |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_OWNER_ID` | از @BotFather | فقط اگر ربات تلگرامی را هم می‌خواهید |

> مخزن **عمومی (public)** است؛ توکن‌ها در Secrets می‌مانند و در کد یا لاگ منتشر نمی‌شوند.

### ۲) جمع‌آوری را اجرا کنید
تب **Actions** ← workflow به نام **collect** ← **Run workflow** ← انتخاب شاخه `main` ← دکمه سبز.

در فرم، هشتگ‌ها و عبارت‌های تلگرام را (با کاما) وارد کنید. بعد از اتمام:
- `data/stores.json` با آخرین فروشگاه‌ها به‌روز می‌شود (خودکار کامیت می‌شود)،
- پوشه `docs/` (سایت) بازسازی می‌شود،
- و یک artifact به نام `stores-json` هم برای دانلود گذاشته می‌شود.

هر بار که اجرا کنید، داده‌های قبلی **حفظ** و جدیدها **ادغام** می‌شوند (بدون رکورد تکراری).

### ۳) سایت را یک‌بار فعال کنید
**Settings → Pages → Build and deployment → Source: Deploy from a branch** ← `main` ← پوشه `/docs` ← Save.

چند دقیقه بعد سایت آدرس ثابت دارد: `https://<کاربر>.github.io/Froshgah/`
و بعد از هر اجرای Actions خودش به‌روز می‌شود. داخل سایت می‌توانید جستجو کنید، بر اساس شهر/دسته/منبع فیلتر بگیرید و شماره تلفن را با یک کلیک کپی کنید.

### (اختیاری) اجرای خودکار هر روز
در انتهای فایل `.github/workflows/collect.yml` چهار خطِ `schedule` کامنت شده است؛ کامنتشان را بردارید تا هر روز صبح خودش اجرا شود.

## اجرا روی کامپیوتر خودتان (برای توسعه)

```bash
pip install -r requirements-dev.txt
cp .env.example .env         # مقادیر را پر کنید
python -m froshgah init
python -m froshgah login     # فقط برای تلگرام، یک‌بار در ترمینال
python -m froshgah run --ig-tags "پوشاک,مانتو" --tg-queries "فروشگاه پوشاک" --limit 25
python -m froshgah search "مانتو تهران"
python -m froshgah site && (cd docs && python -m http.server 8000)   # پیش‌نمایش سایت
pytest -q
```

دستورات دیگر: `collect ig --hashtag ...`، `collect tg "..."`، `latest`، `stats`، `export`، `bot`.

## ربات تلگرام (اختیاری)

ربات یک سرویس **همیشه‌روشن** است و GitHub جای اجراي همیشگی آن نیست (Actions فقط کارهای کوتاه‌مدت اجرا می‌کند، Pages فقط فایل ایستا می‌دهد). سه راه دارید:

1. **همین سایت Pages** را به‌جای ربات استفاده کنید (ساده‌ترین راه — توصیه من).
2. ربات را در **Codespaces** اجرا کنید: روی همین مخزن کلید `.` را بزنید تا یک محیط پایتون آماده در مرورگر باز شود، `python -m froshgah bot` را بزنید و تا وقتی پنجره باز است ربات کار می‌کند.
3. ربات را روی یک **VPS ارزان** نگه دارید (`python -m froshgah bot`) — بقیه چیزها همان‌جا روی GitHub می‌ماند.

دستورات ربات: `/search <عبارت>`، `/latest`، `/stats`، `/collect_ig <هشتگ> [تعداد]` و `/collect_tg <عبارت>` (فقط مدیر).

## محدودیت‌ها ⚠️

- **GitHub IPها را مسدود نمی‌کند، اما اینستاگرام معمولاً IPهای دیتاسنتر را سریع محدود می‌کند.** اگر خطای `429/private profile` دیدید: `limit` را کم کنید، `REQUEST_DELAY` را بالا ببرید، یا در فایل workflow یک **self-hosted runner** روی VPS خودتان هدف بگیرید (راهنمایی داخل همان فایل کامنت شده).
- جستجوی سراسری تلگرام با اکانت کاربری (MTProto) انجام می‌شود و فقط کانال/گروه‌های در دسترس شما را می‌بیند؛ برای بار اول لازم است یک‌بار `login` کنید (محلی یا Codespaces) تا فایل سشن ساخته و در Secret گذاشته شود.
- استفاده از اسپم، تماس دسته‌جمعی یا آزار فروشنده‌ها ممنوع است؛ مسئولیت رعایت ToS اینستاگرام/تلگرام و قوانین محلی با استفاده‌کننده است. این پروژه فقط داده‌های **عمومی** را می‌خواند.

## ساختار پروژه

```
froshgah/            موتور پایتون (استخراج، دیتابیس، جستجو، ربات)
├── run.py           یک اجرای کامل: ادغام ← جمع‌آوری ← JSON ← سایت
├── export.py        دیتابیس ↔ data/stores.json
├── site.py          ساخت پوشه docs/ از روی web/
├── extract.py       استخراج تلفن/آیدی/شهر/دسته از متن
├── normalize.py     نرمال‌سازی فارسی (ی/ی، ک/ک، نیم‌فاصله، ارقام)
├── db.py            SQLite + جستجو
├── bot.py / cli.py  ربات تلگرام و خط فرمان
└── collectors/      instagram.py (instaloader) و telegram.py (Telethon)
web/                 سایت ایستا (HTML/CSS/JS خالص، بدون build، جستجو سمت مرورگر)
data/stores.json     خروجی داده‌ها — در گیت commit می‌شود
docs/                خروجی سایت — منبع انتشار GitHub Pages
.github/workflows/   collect.yml (اجرای درخواستی/cron)
```
